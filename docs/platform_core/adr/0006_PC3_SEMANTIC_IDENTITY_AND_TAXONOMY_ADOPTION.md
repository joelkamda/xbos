# ADR 0006: Stable semantic identity and taxonomy adoption

Status: Accepted for PC3

## Decision

Semantic concepts use an owned namespace and stable code, with non-overlapping effective-dated definitions. Taxonomy nodes remain separate placement/navigation objects and are adopted rather than replaced. Existing nodes without evidence-backed concepts remain valid tenant legacy classifications.

Mappings are explicit directional records typed as exact, broader, narrower, related, or legacy replacement. Classification history snapshots the minimum semantic reference needed for deterministic interpretation.

## Consequences

- Labels, languages, and tree restructuring do not redefine identity.
- Pack and tenant namespaces cannot overwrite kernel or Finance namespaces.
- No universal tree is imposed across industries.
- Atomic Unit and Finance ownership remain unchanged.
- Retirement decisions use read-only impact evidence and retain historical references.
