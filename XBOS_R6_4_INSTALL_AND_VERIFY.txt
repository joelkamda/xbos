Revision 5 — isolated full regression
-------------------------------------
Full pytest regression now runs only against a fresh `xbos_track_b_test`
restored from the latest hash-verified planning backup. The pytest subprocess

Generated bytecode is removed before regression and disabled during pytest so

Revision 6 — bcrypt backend for isolated characterization tests
---------------------------------------------------------------
The WND-server isolated full regression proved the database isolation and
bytecode cleanup, then reached 2075 passing tests with 13 remaining setup
errors. Every remaining error was:

  passlib.exc.MissingBackendError: bcrypt: no backends available

`passlib==1.7.4` is already a production dependency, but the native bcrypt
backend was not present in the new R6.4 control venv.

Revision 6 adds only the isolated control dependency:

  bcrypt==4.2.1

Install/update the control venv with:

  python -m pip install -r requirements-r6-4-control.txt

The acceptance runner now fails fast unless Passlib resolves the `bcrypt`
backend. No live WND runtime package is changed.

Revision 7 — collision-safe diagnostic ports
--------------------------------------------
R6.4 no longer assumes diagnostic ports 8002/8004 are free on the production
server. It selects the first free localhost-only fallback and leaves any
occupied port/process untouched.

Revision 8 — WND API compatibility bridge
-----------------------------------------
R6.5 WND hypercare uses `restaurant.r6.wnd_compat_runtime:app`, not neutral
`main:app`. The explicit R6 adapter preserves every one of the 26 Track-A-only
routes found in the frozen accepted backend while failing closed for non-WND
tenants. Neutral `main:app` remains unchanged.

Revision 9 — WND compatibility OpenAPI annotation binding
----------------------------------------------------------
Revision 8's compatibility route module deferred type annotations, which made
FastAPI/Pydantic 2.11 see imported payload models as unresolved ForwardRefs
through the existing RBAC wrapper. Revision 9 eagerly binds those payload types
inside the temporary WND compatibility module only. No dependency install is
required.
